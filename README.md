Internet Speed Test

Небольшой консольный Python-скрипт для измерения скорости загрузки данных с указанного HTTP-адреса.

Скрипт последовательно выполняет 10 запросов к указанному URL, измеряет время каждого запроса, определяет объём загруженных данных и рассчитывает среднюю скорость загрузки в МБ/с.

Возможности
принимает URL через аргумент командной строки;
выполняет 10 HTTP-запросов последовательно;
измеряет время выполнения каждого запроса;
определяет размер полученных данных;
рассчитывает среднее время выполнения запроса;
рассчитывает общий объём скачанных данных;
рассчитывает среднюю скорость загрузки в МБ/с;
выводит подробную статистику в консоль.

Установка

Клонировать репозиторий:

git clone <URL_РЕПОЗИТОРИЯ>
cd <НАЗВАНИЕ_РЕПОЗИТОРИЯ>

Создать виртуальное окружение:

python -m venv .venv

Активировать его в Windows PowerShell:

.venv\Scripts\Activate.ps1

Установить зависимости:

pip install -r requirements.txt
Запуск

Скрипт принимает URL в качестве аргумента командной строки:

python speed_test.py https://example.com/file.jpg

В качестве URL необходимо использовать существующий адрес файла, доступного для скачивания без авторизации.

Пример работы
Запрос 1: 0.842 сек, 5.21 МБ
Запрос 2: 0.791 сек, 5.21 МБ
Запрос 3: 0.815 сек, 5.21 МБ
Запрос 4: 0.803 сек, 5.21 МБ
...
Запрос 10: 0.803 сек, 5.21 МБ

--- Результат ---
Среднее время запроса: 0.811 сек
Всего скачано: 52.10 МБ
Скорость: 6.42 МБ/с
Принцип работы

Для каждого запроса скрипт:

Запоминает время начала выполнения.
Отправляет HTTP GET-запрос.
Дожидается полного получения ответа.
Определяет размер полученных данных.
Вычисляет время выполнения запроса.
Сохраняет полученные значения.

После выполнения 10 запросов рассчитываются:

Среднее время запроса:

общее время / количество запросов

Средняя скорость загрузки:

общий объём данных / общее время
