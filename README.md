# 🌐 Internet Speed Test

Небольшой консольный Python-скрипт для измерения скорости загрузки данных по HTTP/HTTPS.

Скрипт выполняет **10 последовательных HTTP GET-запросов** к указанному URL, измеряет время каждого запроса, определяет объём загруженных данных и рассчитывает среднюю скорость загрузки в МБ/с.

---

## 🚀 Возможности

* Принимает URL через аргумент командной строки
* Выполняет **10 HTTP-запросов** последовательно
* Устанавливает таймаут запроса — **30 секунд**
* Проверяет HTTP-статус ответа
* Обрабатывает ошибки HTTP-запросов
* Измеряет время выполнения каждого запроса
* Определяет размер загруженных данных
* Рассчитывает среднее время выполнения запроса
* Рассчитывает общий объём скачанных данных
* Рассчитывает среднюю скорость загрузки
* Выводит подробную статистику в консоль

## ▶️ Запуск

Скрипт принимает URL в качестве аргумента командной строки:

```bash

```

Например:

```bash

```

## ⚙️ Принцип работы

Для каждого из 10 запросов программа:

1. Запоминает время начала выполнения с помощью `time.perf_counter()`.
2. Отправляет HTTP GET-запрос через библиотеку `requests`.
3. Устанавливает таймаут **30 секунд**.
4. Проверяет HTTP-статус ответа с помощью `raise_for_status()`.
5. Дожидается получения содержимого ответа.
6. Определяет размер загруженных данных.
7. Вычисляет время выполнения запроса.
8. Сохраняет полученные значения.
9. Выводит информацию о запросе в консоль.

После выполнения всех запросов программа рассчитывает итоговую статистику.

### Среднее время запроса

```text
общее время выполнения запросов / количество запросов
```

### Средняя скорость загрузки

```text
общий объём загруженных данных / общее время выполнения запросов
```

## 🧩 Обработка ошибок

При возникновении ошибки HTTP-запроса программа выводит сообщение и завершает измерение:

```text
Ошибка запроса: ...
```

Для обработки ошибок используется:

```python
except requests.RequestException as e:
```

Это позволяет обработать ошибки соединения, таймауты и HTTP-ошибки.
